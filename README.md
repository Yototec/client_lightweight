# Yototec Market Python Client — Retired

The Polygon-backed Yototec Market service was retired on **October 18, 2026**. Its API at [market.yototec.com](https://market.yototec.com) returns **HTTP 410 Gone** and no longer serves market data.

This SDK is unsupported. Its source remains for historical reference, and its default endpoint is no longer usable. The SDK does not provide a maintained replacement service.

Previously published `yototec` package versions may remain available on PyPI. Installing those versions does not restore access to the retired service. Installation and usage instructions have been removed from this repository.

Service retirement is separate from cancellation of the Polygon subscription. Provider subscriptions and billing must be managed separately.
